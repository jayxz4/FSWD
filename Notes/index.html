JAVASCRIPT NOTES

1. Introduction to JavaScript

Definition

JavaScript is a programming language used to make web pages interactive and dynamic. It works together with HTML and CSS to create modern web applications.

Example

console.log("Hello JavaScript");

Output

Hello JavaScript

2. Variables

Definition

A variable is a container used to store data values. The value stored in a variable can be used later in a program.

Syntax

let variableName = value;

Example

let name = "Sanjay";
let age = 21;

console.log(name);
console.log(age);

Output

Sanjay
21

Types of Variable Declaration

  • var - Used to declare variables using the older JavaScript syntax.
  • let - Used when the value of a variable may change.
  • const - Used when a variable should not be reassigned.

3. Data Types

Definition

Data types define the type of value that a variable can store in JavaScript.

Types of Data Types

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • Object
  • BigInt
  • Symbol

Example

let name = "Sanjay";
let age = 21;
let student = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof student);

Output

string
number
boolean

4. Operators

Definition

Operators are symbols used to perform different operations on values and variables.

Types of Operators

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators
  • Ternary Operator

Example

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Output

15
5
50
2

5. If...Else Statement

Definition

The if...else statement is used to execute different blocks of code depending on whether a condition is true or false.

Syntax

if (condition) {

    // code if condition is true

} else {

    // code if condition is false

}

Example

let age = 20;

if (age >= 18) {

    console.log("Eligible to vote");

} else {

    console.log("Not eligible to vote");

}

Output

Eligible to vote

Key Points

  • if checks a condition.
  • If the condition is true, the if block executes.
  • If the condition is false, the else block executes.

6. Switch Statement

Definition

The switch statement is used to execute one block of code from multiple possible cases.

Syntax

switch (expression) {

    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // code

}

Example

let day = 2;
switch (day) {

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Invalid day");

}

Output

Tuesday

7. Loops

Definition

Loops are used to execute a block of code repeatedly until a specified condition is met.

Types of Loops

  • for loop
  • while loop
  • do...while loop
  • for...of loop
  • for...in loop

Example - for Loop

for (let i = 1; i <= 5; i++) {

    console.log(i);

}

Output

1
2
3
4
5

9. Arrays

Definition

An array is a special variable used to store multiple values in a single variable.

Syntax

let arrayName = [value1, value2, value3];

Example

let fruits = [
    "Apple",
    "Mango",
    "Orange"
];

console.log(fruits[0]);

Output

Apple
